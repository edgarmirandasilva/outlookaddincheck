# Assets Directory

This directory should contain icon images for the Outlook add-in:

- icon-16.png (16x16 pixels)
- icon-32.png (32x32 pixels)
- icon-64.png (64x64 pixels)
- icon-80.png (80x80 pixels)

You can create these icons using any image editor or icon generator service.

Recommended colors:
- Primary: Blue (#0078d4) - Microsoft Office Blue
- Accent: Green (#28a745) - For completed state
- Warning: Orange/Yellow (#ffd700) - For pending state

The icons should represent email/flag/follow-up concepts.
